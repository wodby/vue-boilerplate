# Vue boilerplate

A Vue starter for [Wodby](https://wodby.com), generated with `create-vue` and built with Vite.

## Local development

```sh
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```sh
npm run build
```

The static application is written to `dist`. The included Wodby CI pipeline builds and publishes that directory. This boilerplate is used by the [Vue service](https://github.com/wodby/service-vue) and [Vue stack](https://github.com/wodby/stack-vue).
